- `style.css` — Responsive styling

## Publish with GitHub Pages
1. Create a new public repository named `abraham-takale.github.io` **if you want this at your main profile URL**. If using an existing repository, open that repository instead.
2. Upload `index.html`, `resume.html`, and `style.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.

## Privacy
The private project name and repository URL are intentionally not included. This website is separate from your private project repository. Do not add confidential project details to a public website.

## Before publishing
- Replace “Add your email” in `resume.html` with an email you want to publish, or remove that line.
- Review every skill and project bullet to ensure it accurately reflects your experience.
